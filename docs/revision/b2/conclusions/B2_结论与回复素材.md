## 二、B2 方法（ThyroidXAgent 主 pipeline）

- **输入**：`output/<队列>/pipeline_run/results.json`；分割另用 `intermediate/selected_masks.npz` + 队列 GT mask 目录。  
- **Bootstrap**：**1000** 次，**seed=42**，95% 百分位区间。  
- **Cluster 重采样**：有 patient map 时按 **患者 ID** 重采样再展开到图像；无 map 时 **一图一簇**。  
- **分类分数**：与 pipeline 评估一致——`final_label` + `final_confidence` 转为恶性类概率。  
- **患者级分类（主分析）**：同一患者多图恶性概率 **算术平均**；患者标签为组内图像标签的 **max**（任一张恶性→恶性）。  
- **分割**：逐图 Dice（预测 mask vs GT），cluster bootstrap 对 Dice 做重采样；有 patient map 时另报 **患者内 Dice 均值** 的患者级 bootstrap。

**与旧 `metrics.json` 的关系**：TN3K/TN5K（一图一簇）分类 CI 与旧图像级 bootstrap **一致**；ThyroidXL、ZJH 图像级 cluster CI **略宽于**原图像级 i.i.d. bootstrap，符合预期。
