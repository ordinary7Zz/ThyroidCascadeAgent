**可写入回复的表述（中文）**：  
除 **ZJH-8K** 与 **ThyroidXL** 外，本次使用的公开或机构释放标注均为**图像级**，未提供可复现的 patient-level 键；对这些队列，我们将 bootstrap 重采样的单位设为**单张图像**（一图一簇），并在 Methods 中明确说明。ZJH-8K 与 ThyroidXL 在患者级分析中使用可解析的 patient ID。

**英文 Methods 草稿**：  
*Patient-level clustering was applied to ZJH-8K and ThyroidXL using release-documented patient keys. For all other ultrasound cohorts without public patient identifiers, each image was treated as an independent cluster for bootstrap resampling; image-level metrics are reported accordingly.*

### 2.2 训练堆叠 vs 外部测试（**dHash 近重复，B1 主结论**）

**方法**：64-bit 差分哈希（dHash），堆叠 train = `dataset_3` + `dataset_4` 的 train（去重路径后 **38,518** 张），Hamming ≤ **5** 为近重复；**H=0** 为哈希完全一致（高置信同图，建议人工抽复核）。

| 对比 | 外测图数 | 配对数（去重后） | H=0 | 仅近重复 (1–5) |
|------|----------|------------------|-----|----------------|
| stacked train vs **TN3K test** | 614 | 5 | 0 | 5 |
| stacked train vs **TN5K test** | 1000 | 44 | **38** | 6 |
| stacked train vs **ThyroidXL test** | 2090 | 2 | 0 | 2 |
| stacked train vs **ZJH-8K** | 7958 | **1123** | **995** | 128 |
| stacked train vs DDTI / PKTN test | 191 / 150 | 3 / 0 | 0 | — |

**TN3K（train+valid+test 官方划分） vs ZJH-8K**（同院图级交叉）：**1333** 对（**1156** H=0）；**TN3K test only vs ZJH**：**39** 对（**2** H=0）。

**可写入回复的结论（中文）**：

- 各外测与堆叠训练在 **文件名 stem 上无交集**（脚本 `audit_train_test_overlap.py`），但因 **跨库命名规则不同**（如 TN3K 保留数据集前缀、ZJH 为院内命名），**该结果不能作为「无训练–测试泄漏」的依据**，稿面**不强调**。
- **内容级筛查**显示：堆叠 train 与 **ZJH-8K** 存在 **大量视觉重复**（约 **995** 张哈希完全一致）；与 **TN5K test** 亦有 **38** 对完全一致（train/test **文件名编号不同**）。说明泄漏风险在 **像素/重复收录**，不在「同名文件是否拷入 train 目录」。
- **TN3K test** 与 ZJH 完全同哈希仅 **2** 张；同院重复主要集中在 **TN3K train（等在堆叠中）↔ ZJH 外测**。

**英文 Methods 草稿（替换 stem 叙述）**：  
*We screened stacked training images against each external test cohort using 64-bit difference hashing (Hamming distance ≤ 5). Filename-level overlap was not used as evidence of independence because cohorts use incompatible naming schemes (e.g., TN3K release names vs. ZJH institutional filenames). We report counts of exact (H = 0) and near-duplicate pairs and optionally sensitivity metrics excluding H = 0 matches to training.*

### 2.3 stem 检查（仅工程记录，**不作为 B1/回复主结论**）

## 三、审稿回复可用段落（中文草稿）

**R1.1 / R2.2（数据边界与独立性，B1 部分）**  
我们已对各队列核查是否具备可公开的 patient identifier：仅 **ZJH-8K** 与 **ThyroidXL** 可在本地复现患者级聚类（分别为 1146 例 / 7958 图、739 例 / 2090 图）。对其余队列，bootstrap 将每张图像视为独立聚类单位，并明确报告图像级指标。  
**训练–外测独立性**以 **感知哈希（dHash）** 筛查为准（非文件名比对）：堆叠训练与 **ZJH-8K** 存在 **995** 对哈希完全一致图像、与 **TN5K test** 存在 **38** 对完全一致图像；**TN3K test** 与 ZJH 仅 **2** 对完全一致。TN3K 与 ZJH-8K 同属珠江医院，图级重复与（若可获得）院内患者 ID 交叉核对见补充材料。（聚类 bootstrap 与患者级 AUROC 见 B2。）

「各外测与训练堆叠文件名无交集故无泄漏」——跨库命名不同，该说法**不成立**。

**局限句（建议保留）**  
TN3K 公开包无 patient ID；同院 **患者级**重叠统计依赖院内记录（F6）。主外测 **ZJH** 指标对剔除 train-重复图的敏感性分析见 [Supp. / 待补]。
