## 二、英文回复草稿（R2.14，可贴回复信）

We thank the reviewer for raising baseline fairness. We clarified in the revised Methods and new **Supplementary Table S[X]** that all **supervised** segmentation baselines in Table S3 were fine-tuned on the same four-cohort stacked development set (dataset_4: TN3K, ThyroidXL, PKTN, TN5K), and all **supervised** classification baselines in Table S4 were fine-tuned on the same three-cohort stacked development set (dataset_3: TN3K, ThyroidXL, TN5K), starting from publicly available upstream pretraining. ThyroidXAgent full-stack results use the same stacked development data; progressive stacking ablations (Table S6) are reported separately. Vision–language baselines, where shown, were evaluated zero-shot or via API with fixed prompts and are documented in a separate block. External cohorts (e.g., ZJH-8K, DDTI) were used **only for testing**. Cluster-bootstrap confidence intervals in Tables S3/S4 are described in Methods §4.6.
