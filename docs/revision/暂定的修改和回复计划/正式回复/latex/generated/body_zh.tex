\noindent 1.~分割 LLM 路由
\par
运行设定：启用 LLM 路由；prompt 中包含候选间分歧度量；使用完整设备/来源元数据（「完整元数据」条件，见 \responsetablerefrange{tab_metadata_ablation_seg}{tab_metadata_ablation_cls}）；纳入各候选 mask 的放射组学裁判摘要；每次仅选择单个 mask。\par
System（基础段，始终使用）：\par
\begin{promptverbatim}
你是分割模型选择代理。根据 user 中 JSON 指标选最佳 mask。
禁止输出思考过程、Markdown 或任何 JSON 外的文字。第一个字符必须是 {，最后一个必须是 }。
只输出一行 JSON："selected_model", "confidence"(0-1)；勿输出 reasoning 字段。示例：{"selected_model":"模型名", "confidence":0.9}
优先级：agreement_with_others↑；分歧大时 mean_hd95_to_others↓；radiomics_judge 与 classification_anchor 一致者优先；形态学与设备匹配次之。
\end{promptverbatim}
System 追加（运行时，一行）：当所有独立分类模型 top 类一致时，追加分类锚点说明（例：「分类锚点：恶性。与锚点矛盾的 \texttt{radiomics\_judge} 降权。」）；不一致时追加「无分类锚点。以 radiomics 内部一致性与 agreement 为主。」\par
User 消息：程序拼接的 JSON，含设备/来源（元数据消融条件下可隐去）、候选间分歧摘要、各候选 mask 的质量与 radiomics\_judge 字段，以及 \texttt{classification\_anchor}（一致时为类别字符串，不一致时为 null）。\par
模型输出：单行 JSON，字段 \texttt{selected\_model}、\texttt{confidence}（不含 \texttt{reasoning}）。\par
非 LLM 回退：关闭 LLM 路由或 API/解析失败时，使用确定性规则静态选择器。\par
\noindent 2.~分类 --- 独立 LLM 路由（所有独立分类模型 top 类一致时不调用 LLM）
\par
所有独立分类模型 top 类一致时，采用确定性共识（取 top\_confidence 最高者），不调用 LLM。\par
System（单专家选择，$k{=}1$）：\par
\begin{promptverbatim}
从 user JSON  predictions 中选最可信模型。
禁止思考/Markdown。只输出一行 JSON：selected_model, selected_class, confidence(0-1)。勿输出 reasoning 字段。
\end{promptverbatim}
System（多模型概率融合，$k>1$）：\par
\begin{promptverbatim}
你是甲状腺超声多模型预测整合专家，选出最值得信任的 k 个模型（k 由运行配置指定，按信任度从高到低），用于对各类别概率取平均融合。
【输出】只输出纯JSON（无Markdown/思考），首尾为{}。字段：selected_models（长度恰好为 k 的字符串数组）。勿输出 reasoning、selected_class 或 confidence。
\end{promptverbatim}
User 消息：设备信息（元数据条件下可隐去）与各模型预测 JSON（由程序拼接；含本次路由的 $k$）。\par
模型输出：$k{=}1$ 时为 \texttt{selected\_model}、\texttt{selected\_class}、\texttt{confidence}；$k>1$ 时仅为长度 $k$ 的 \texttt{selected\_models} 数组（均不含 \texttt{reasoning}）。\par
\noindent 3.~分类 --- 分类器不一致时的 LLM 裁决
\par
System：\par
\begin{promptverbatim}
甲状腺超声分类裁决：各独立分类模型未形成共识。
依据 user JSON 中的 independent_models、autogluon_based_on_selected_mask、segmentation_decision。
禁止思考过程与 Markdown。只输出一行 JSON：
{"selected_class":"恶性或良性", "confidence":0.0-1.0}
勿输出 reasoning 字段。信号均模糊时略倾向恶性但降低 confidence。
\end{promptverbatim}
User 消息：单条 JSON，含场景说明、\texttt{independent\_models}（全部独立分类模型）、基于所选 mask 的 AutoGluon 预测（可缺失）、\texttt{segmentation\_decision}（含所选分割专家名称，不含 LLM 自然语言理由）。\par
模型输出：单行 JSON---\texttt{selected\_class}、\texttt{confidence}（不含 \texttt{reasoning}）；路由记录标记「分类器不一致时的 LLM 裁决」且「已调用 LLM」。\par
