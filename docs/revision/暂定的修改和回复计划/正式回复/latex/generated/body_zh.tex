\noindent 1.~分割 LLM 路由
\par
运行设定：启用 LLM 路由；prompt 中包含候选间分歧度量；使用完整设备/来源元数据（与投稿补充材料 S4 路由设定一致）；纳入各候选 mask 的放射组学裁判摘要；每次仅选择单个 mask。\par
System（基础段，始终使用）：\par
\begin{promptverbatim}
你是分割模型选择代理。根据 user 消息中的结构化指标选最佳 mask。
禁止输出思考过程、Markdown 或 JSON 外的文字。只输出一行 JSON，须包含：所选模型名称、0--1 置信度、理由（固定为「-」）。
优先级：候选 mask 间一致度更高者优先；分歧大时与其他候选平均 Hausdorff 距离更低者优先；放射组学裁判与独立分类锚点一致者优先；形态学合理性与设备匹配次之。
\end{promptverbatim}
System 追加（可选）--- 独立分类模型一致时，提供分类锚点（示例为「恶性」）：\par
\begin{promptverbatim}

【分类锚点（关键信号）】
独立分类模型（3个，无需mask）一致判断该图像为「恶性」。
此锚点用于评估各分割结果的合理性：
- 与锚点矛盾的Radiomics裁判分类 → 该mask可能覆盖了错误的ROI → 可信度显著降低。
- 与锚点吻合的mask → 额外加分。
- 若所有mask的Radiomics分类都与锚点矛盾 → 选置信度最高的 mask 并解释原因。
\end{promptverbatim}
System 追加（可选）--- 独立分类模型不一致时（无分类锚点）：\par
\begin{promptverbatim}

【无分类锚点】
独立分类模型对该图像的判断不一致，未能形成共识。
整图级别特征模糊，分割评估应以以下为主要依据：
1. Radiomics裁判的内部一致性（不同的分割得到相似的分类方向→更可信）
2. 形态学合理性（circularity 0.6-0.9、单连通）
3. 设备匹配与历史性能
\end{promptverbatim}
User 消息：由程序拼接---可选分歧度量摘要、设备与数据来源行、各候选分割模型的质量评估（含放射组学裁判与分歧信息），并以自然语言要求模型仅输出一行 JSON（所选专家名称、0--1 置信度、固定占位理由），字段要求与附录 A1 中 System 段一致。\par
\par
模型输出：单行 JSON，包含所选分割专家、置信度与理由（理由在部署中固定为占位符 ``-''）。\par
非 LLM 回退：关闭 LLM 路由或 API/解析失败时，使用确定性规则静态选择器。\par
\noindent 2.~分类 --- 独立 LLM 路由（三名模型预测一致时不调用 LLM）
\par
三名独立分类模型 top 类一致时，采用确定性共识，不调用 LLM。\par
System（单专家选择）：\par
\begin{promptverbatim}
从 user 消息中的各模型预测摘要中选最可信模型。
禁止思考/Markdown。只输出一行 JSON，须包含：所选模型名称、预测良恶性类别、0--1 置信度、理由（固定为「-」）。
\end{promptverbatim}
System（多模型概率融合，$k{=}5$）：选出 5 个模型做概率融合；输出所选模型列表与简短理由（不输出单一良恶性类别标签）。\par
User 消息：设备信息、各模型预测摘要与问题句（由程序拼接）。\par
\noindent 3.~分类 --- 分类器不一致时的 LLM 裁决
\par
System：\par
\begin{promptverbatim}
你是甲状腺超声诊断专家。独立分类模型对该图像判断不一致，你需要综合所有信号，自己做出最终的良恶性判断。

你将收到：
1. 独立分类模型预测（3个，无需mask，整图判断）
2. AutoGluon 基于分割筛选 mask 的 Radiomics 分类（有 ROI 引导）
3. 分割路由对该 mask 的选择理由

若所有信号都模糊，保守倾向恶性（宁可假阳性不可假阴性），但标注低置信度。
