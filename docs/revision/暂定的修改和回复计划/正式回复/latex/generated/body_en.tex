\textbf{1. Segmentation LLM routing}
\par
\begin{itemize}
\item Runtime settings: LLM routing enabled; disagreement metrics included in the prompt; full device/source metadata (manuscript S4); radiomics-judge summaries per candidate mask; single-mask selection per case.
\item \textbf{System (base, always used):}
\end{itemize}
\begin{promptverbatim}
You are a segmentation model selection agent. Choose the best mask from the structured metrics in the user message.
Do not output chain-of-thought, Markdown, or any text outside JSON. Output one JSON line with: chosen model name, confidence in [0,1], and rationale (fixed to "-").
Priority: higher inter-candidate mask agreement; when experts disagree, lower mean Hausdorff distance to other candidates; prefer masks whose radiomics judge aligns with the independent classification anchor; morphology and device match are secondary.
\end{promptverbatim}
\begin{itemize}
\item \textbf{Optional system append --- independent classifiers agree} (classification anchor; example «malignant»):
\end{itemize}
\begin{promptverbatim}

[Classification anchor (key signal)]
Three independent classifiers (no mask required) unanimously label this image as malignant.
Use this anchor to judge each segmentation:
- Radiomics-judge class contradicting the anchor → the mask may cover the wrong ROI → substantially lower trust.
- Mask consistent with the anchor → bonus.
- If all masks’ radiomics classes contradict the anchor → select the mask with highest confidence and explain why.
\end{promptverbatim}
\begin{itemize}
\item \textbf{Optional system append --- independent classifiers disagree} (no classification anchor):
\end{itemize}
\begin{promptverbatim}

[No classification anchor]
Independent classifiers disagree; no consensus.
Whole-image features are ambiguous. Prioritize:
1. Internal consistency of radiomics judges (similar class direction across masks → more trustworthy)
2. Morphologic plausibility (circularity 0.6–0.9, single connected component)
3. Device match and historical performance
\end{promptverbatim}
\begin{itemize}
\item \textbf{User message}: assembled by the pipeline---optional disagreement summary, device/data lines, per-candidate segmentation quality (including radiomics-judge and disagreement summaries), and a natural-language instruction to output \textbf{one line of JSON only} (chosen expert name, confidence in [0,1], fixed placeholder rationale); see the System example below.
\end{itemize}
\par
\begin{itemize}
\item \textbf{Model output}: one JSON line with the chosen segmentation expert, confidence, and rationale (deployment uses ``-'' as a fixed placeholder rationale).
\item \textbf{Non-LLM fallbacks}: if LLM routing is off or the API/parse fails, a deterministic rule-based static selector is used.
\end{itemize}
\textbf{2. Classification --- standalone LLM router (no LLM when three classifiers agree)}
\par
\begin{itemize}
\item When all three independent classifiers share the same top class, deterministic consensus is used with no LLM call.
\item \textbf{System (single-expert selection)}:
\end{itemize}
\begin{promptverbatim}
From the per-model prediction summaries in the user message, select the most trustworthy model.
No chain-of-thought or Markdown. Output one JSON line with: chosen model name, predicted benign/malignant class, confidence in [0,1], rationale fixed to "-".
\end{promptverbatim}
\begin{itemize}
\item \textbf{System ($k{=}5$ probability fusion)}: select five models for probability fusion; output the chosen model list and brief rationale (no single benign/malignant class label).
\item \textbf{User message}: device information, per-model prediction summaries, and the question sentence (assembled by the pipeline).
\end{itemize}
\textbf{3. Classification --- LLM arbitration (three independent classifiers disagree)}
\par
\begin{itemize}
\item \textbf{System}:
\end{itemize}
\begin{promptverbatim}
You are a thyroid ultrasound diagnostic expert. Independent classifiers disagree on this image; synthesize all signals and make the final benign/malignant call.

You will receive:
1. Predictions from three independent classifiers (no mask; whole-image)
2. AutoGluon radiomics classification on the segmentation-selected mask (ROI-guided)
3. Reasoning from the segmentation agent for that mask

If all signals are ambiguous, bias conservatively toward malignant (prefer false positives over false negatives) but report low confidence.

Output pure JSON (no Markdown/code fences): final benign/malignant class, confidence in [0,1], and a brief rationale that cites specific confidence values (class labels match the deployment locale).
\end{promptverbatim}
\begin{itemize}
\item \textbf{User message}: one structured text block with (i) scenario text (classifiers disagree); (ii) predictions and confidences from three independent classifiers; (iii) AutoGluon radiomics prediction on the selected mask (marked missing if unavailable); (iv) segmentation routing conclusion and rationale; (v) a question requesting the final benign/malignant label and confidence.
\end{itemize}
\begin{itemize}
\item \textbf{Model output}: one JSON line---final benign/malignant class, confidence in [0,1], and a brief rationale citing numeric confidences; the routing record marks ``LLM arbitration'' and ``LLM invoked.''
\end{itemize}
\textbf{4. Classification --- deterministic consensus (three classifiers agree)}: \textbf{no LLM}; the routing record marks ``classification consensus.''
