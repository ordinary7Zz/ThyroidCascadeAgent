\reviewersection{Reviewer 1, Comment 2 (R1.2)}
\begin{reviewercomment}

\begin{authorresponse}
We thank the reviewer for this important suggestion. On a fixed pool of trained segmentation/classification experts, we added a systematic routing ablation on each expert's candidate masks and malignancy probabilities, changing only downstream expert selection, fusion/arbitration, and in the full system LLM routing and evidence fusion. Full numbers are in \responsetablerefrange{tab_routing_ablation_seg}{tab_routing_ablation_cls}.\par
Eight comparison strategies (numbered as in \responsetablerefrange{tab_routing_ablation_seg}{tab_routing_ablation_cls}): (1)~validation-selected best single expert: on the validation split, select the pool member with highest mean mask Dice versus reference masks for segmentation and highest AUROC for classification; segmentation and classification may select different experts; on each external test set, always use that expert's frozen candidate outputs without retraining underlying experts; (2)~soft voting: on frozen candidates, segmentation uses equal-weight averaging of candidate masks with threshold 0.5; classification uses the arithmetic average of independent classifiers' class probabilities; (3)~majority vote: segmentation uses per-pixel majority among candidate masks; classification uses majority vote over independent classifiers' discrete labels; (4)~static rule (segmentation: for each expert, compute the mean pairwise mask IoU between its candidate and every other candidate, and select that expert's mask; classification: among independent classifiers, take the highest malignancy confidence, tie-break lower prediction entropy); (5)~max-confidence: segmentation selects the single expert with the highest mean mask confidence; classification selects the single independent classifier with the highest malignancy confidence; (6)~non-LLM multinomial logistic routers fit separately for segmentation and classification on validation quality and disagreement features, with weights frozen on test (details in Reviewer 3, Comment 1); (7)~deployable full ThyroidXAgent (external-test protocol in \responsetableref{tab_baseline_protocol} and ThyroidXAgent rows in \responsetableref{tab_cls_ext} and \responsetableref{tab_seg_ext}; strategy (7) numbers in \responsetablerefrange{tab_routing_ablation_seg}{tab_routing_ablation_cls}); (8)~non-deployable oracle upper bound: on each test case, segmentation selects the pool expert with highest mask Dice versus reference masks; classification selects the highest-confidence independent classifier among those correct against ground-truth labels.\par
\responsetablerefrange{tab_routing_ablation_seg}{tab_routing_ablation_cls} report all eight strategies (1)--(8) on each cohort's test set. These IDs are for this ablation only. 95\% CIs follow Reviewer 2, Comment 2 (R2.2).\par
Main findings: (i) No single static strategy dominates all cohorts and tasks; interpret with 95\% CIs (overlap is common). (ii) Segmentation: max-confidence can underperform mask/probability ensembling on several cohorts; non-deployable oracle upper bounds exceed best deployable static routes (\responsetablerefrange{tab_routing_ablation_seg}{tab_routing_ablation_cls}). \rpending{One or two cohort-level segmentation contrasts with point estimates and CIs from Tables R12--R13, e.g.\ max-confidence vs soft voting on TN3K/TN5K}. \noindent 1.~Segmentation LLM routing
\par
Runtime settings: LLM routing enabled; disagreement metrics included in the prompt; full device/source metadata (full-metadata condition in \responsetablerefrange{tab_metadata_ablation_seg}{tab_metadata_ablation_cls}); radiomics-judge summaries per candidate mask; single-mask selection per case.\par
System (base, always used):\par
\begin{promptverbatim}
You are a segmentation model selection agent. Choose the best mask from the structured metrics in the user message.
Do not output chain-of-thought, Markdown, or any text outside JSON. Output one JSON line with: chosen model name, confidence in [0,1], and rationale (fixed to "-").
Priority: higher inter-candidate mask agreement; when experts disagree, lower mean Hausdorff distance to other candidates; prefer masks whose radiomics judge aligns with the independent classification anchor; morphology and device match are secondary.
\end{promptverbatim}
Optional system append --- independent classifiers agree (classification anchor; example «malignant»):\par
\begin{promptverbatim}

[Classification anchor (key signal)]
Three independent classifiers (no mask required) unanimously label this image as malignant.
Use this anchor to judge each segmentation:
- Radiomics-judge class contradicting the anchor → the mask may cover the wrong ROI → substantially lower trust.
- Mask consistent with the anchor → bonus.
- If all masks’ radiomics classes contradict the anchor → select the mask with highest confidence and explain why.
\end{promptverbatim}
Optional system append --- independent classifiers disagree (no classification anchor):\par
\begin{promptverbatim}

[No classification anchor]
Independent classifiers disagree; no consensus.
Whole-image features are ambiguous. Prioritize:
1. Internal consistency of radiomics judges (similar class direction across masks → more trustworthy)
2. Morphologic plausibility (circularity 0.6–0.9, single connected component)
3. Device match and historical performance
\end{promptverbatim}
User message: assembled by the program---optional disagreement summary, device/data lines, per-candidate segmentation quality (including radiomics-judge and disagreement summaries), and a natural-language instruction to output one line of JSON only (chosen expert name, confidence in [0,1], fixed placeholder rationale); JSON field requirements match the System prompt blocks in Appendix~A1.\par
\par
Model output: one JSON line with the chosen segmentation expert, confidence, and rationale (deployment uses ``-'' as a fixed placeholder rationale).\par
Non-LLM fallbacks: if LLM routing is off or the API/parse fails, a deterministic rule-based static selector is used.\par
\noindent 2.~Classification --- standalone LLM router (no LLM when three classifiers agree)
\par
When all three independent classifiers share the same top class, deterministic consensus is used with no LLM call.\par
System (single-expert selection):\par
\begin{promptverbatim}
From the per-model prediction summaries in the user message, select the most trustworthy model.
No chain-of-thought or Markdown. Output one JSON line with: chosen model name, predicted benign/malignant class, confidence in [0,1], rationale fixed to "-".
\end{promptverbatim}
System ($k{=}5$ probability fusion): select five models for probability fusion; output the chosen model list and brief rationale (no single benign/malignant class label).\par
User message: device information, per-model prediction summaries, and the question sentence (assembled by the program).\par
\noindent 3.~Classification --- LLM arbitration when classifiers disagree
\par
System:\par
\begin{promptverbatim}
You are a thyroid ultrasound diagnostic expert. Independent classifiers disagree on this image; synthesize all signals and make the final benign/malignant call.

You will receive:
1. Predictions from three independent classifiers (no mask; whole-image)
2. AutoGluon radiomics classification on the segmentation-selected mask (ROI-guided)
3. Reasoning from the segmentation agent for that mask

If all signals are ambiguous, bias conservatively toward malignant (prefer false positives over false negatives) but report low confidence.

Output pure JSON (no Markdown/code fences): final benign/malignant class, confidence in [0,1], and a brief rationale that cites specific confidence values (class labels match the deployment locale).
\end{promptverbatim}
User message: one structured text block with (i) scenario text (classifiers disagree); (ii) predictions and confidences from three independent classifiers; (iii) AutoGluon radiomics prediction on the selected mask (marked missing if unavailable); (iv) segmentation routing conclusion and rationale; (v) a question requesting the final benign/malignant label and confidence.\par
Model output: one JSON line---final benign/malignant class, confidence in [0,1], and a brief rationale citing numeric confidences; the routing record marks ``LLM arbitration'' and ``LLM invoked.''\par
